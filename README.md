# Ecological tank species labels

22 species and groups, each displayed as a silhouette on the left with Chinese and scientific names on the right.

生态缸物种标签：22个物种与类群，剪影居左，中文名与科学名居右。

Open `index.html`, or visit the GitHub Pages site after deployment. The page is self-contained and supports printing.

Source credits and interpretation scopes are recorded in [CREDITS.md](CREDITS.md). Some silhouettes show individual arm plates, shells or colony fragments. AI-generated restorations and derivatives are identified in the credits.
